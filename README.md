## Current work

- **[Ion](https://github.com/nijaru/ion)** — A terminal coding agent with a Rust SDK.
- **Pi extensions** — Extensions for the Pi coding agent, including [background subagents](https://github.com/nijaru/pi-subagents), [agent-controlled compaction](https://github.com/nijaru/pi-compactor), and [web fetch and search](https://github.com/nijaru/pi-search).
- **Vero** *(private)* — A systems programming language and compiler built on MLIR/LLVM.
- **[Ribn](https://github.com/nijaru/ribn)** — A model inference and serving engine with a native Rust API.

## Other projects

- **[brotli](https://github.com/nijaru/brotli)** — A modern, pure-Go Brotli library with streaming, block, and iterator APIs.
- **[Brutli](https://github.com/nijaru/brutli)** — A from-scratch Brotli encoder and decoder in Rust.
- **[OmenDB](https://github.com/omendb/omendb)** — A relational database server with PostgreSQL client support and a Rust API.
- **[go-clob-client](https://github.com/nijaru/go-clob-client)** — An unofficial Go SDK for Polymarket’s trading and market-data APIs.
- **[Chassis](https://github.com/nijaru/chassis)** — A framework for making audio software in Rust.
- **[Stop](https://github.com/nijaru/stop)** — A command-line process monitor for macOS and Linux, with process trees and port lookups.
